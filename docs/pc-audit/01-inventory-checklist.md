# Аудит домашнего ПК · Шаг 1. Инвентаризация

Цель аудита: понять реальные возможности ПК для дохода (майнинг, ноды, торговые боты, локальный AI, аренда вычислений, рендер и т. д.) и посчитать экономику каждого варианта.

Правило: выводы только по полному набору данных. Результаты сбора **не коммитим в этот репозиторий** (он публичный), присылаем в чат.

## A. Автоматический сбор (5 минут)

1. Скачай `collect-pc-info.ps1` из этой папки.
2. Пуск → набери `PowerShell` → правой кнопкой → «Запуск от имени администратора».
3. Выполни:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass -Force
   cd $HOME\Downloads
   .\collect-pc-info.ps1
   ```
4. На Рабочем столе появится `pc-audit-<дата>.txt`. Пришли его содержимое.

Скрипт только читает данные и ничего не меняет.

## B. Что скрипт не видит: нужны фото или ручная проверка

| Что | Как получить |
|---|---|
| Блок питания | Фото наклейки на БП (сбоку корпуса или снизу). Нужны: модель, мощность в ваттах, сертификат 80 PLUS (Bronze/Gold и т. п.), год выпуска. |
| Температуры CPU/GPU в простое и под нагрузкой | HWiNFO64 (hwinfo.com, бесплатно) → Sensors-only → снимок экрана через 5 минут простоя. Затем запусти нагрузку (игру на 10–15 минут, или FurMark + Cinebench R23), сделай второй снимок. Нужны: CPU Package, GPU Temperature, GPU Hot Spot, GPU Power, CPU Package Power. |
| Скорость интернета | speedtest.net → download / upload / ping. |
| Тип IP-адреса | 2ip.ru или личный кабинет провайдера: белый (статический/публичный) или серый (NAT). Это решает, можно ли держать ноды и серверы. |
| Тариф на интернет | Безлимит или нет, ограничение по трафику. |
| Корпус и охлаждение | Одно фото открытого корпуса: кулер CPU (боксовый/башня/водянка), число вентиляторов, пыль. |
| Видеокарта (если скрипт не показал VRAM) | Win+R → `dxdiag` → вкладка «Экран» → «Память экрана». |
| Материнская плата (если скрипт показал «To be filled by O.E.M.») | Надпись на самой плате между слотами PCIe или в BIOS (F2/Del при загрузке). |

## C. Данные для экономики (без них расчёт невозможен)

1. **Тариф на электричество**, руб/кВт·ч. Если есть день/ночь, оба значения. Смотри в квитанции или на сайте гарантирующего поставщика.
2. **Город/регион** и **страна**. Влияет на тарифы, климат (охлаждение летом) и правовые ограничения.
3. **Сколько часов в сутки ПК свободен** для фоновых задач. Он же твой рабочий/игровой компьютер или может стоять под нагрузкой 24/7?
4. **Где стоит ПК**: жилая комната, кладовка, балкон. Шум и тепло 24/7 приемлемы?
5. **Бюджет на модернизацию**, если готов рассматривать: 0 / до 20 тыс. / до 60 тыс. / больше.
6. **Что уже есть**: аккаунты на биржах, кошельки, опыт с Linux/Docker, Python.
7. **Отношение к риску**: только пассивные и предсказуемые варианты или готов к волатильности (крипта, торговля).

## D. Что будет дальше

После получения данных: оценка железа и узких мест → расчёт майнинга/нод/ботов на актуальных данных из интернета (с датой источника) → немайнинговые варианты (AI, рендер, аренда, серверы) → экономика каждого варианта (вложения → расходы → выручка → чистый результат → окупаемость → риски) → модернизация в двух бюджетах → итоговый отчёт A–G с пошаговым планом.
