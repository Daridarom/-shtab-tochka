# Ветка telemetry

Сюда локальный коллектор ЦУП пишет только безопасную проекцию состояния `live/status.json` (без текстов сообщений, идентификаторов и токенов). Деплои Vercel для этой ветки выключены через `vercel.json`, поэтому телеметрические коммиты не расходуют лимит деплоев. Приложение читает файл по raw-адресу ветки.
